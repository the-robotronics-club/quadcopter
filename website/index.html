01 — Overview

Built for the mountains, proven on the bench

A complete autonomy stack for standard multirotor platforms, developed and tested by the Robotronics Club at IIT Mandi for real-world deployment in challenging terrain.

Autonomous Navigation

Real-time 3D path planning with dynamic occupancy-grid mapping and trajectory optimization.

State Estimation

Visual-Inertial Odometry fused with an extended Kalman filter for GPS-denied operation.

Vision on the Edge

YOLOv8 detection, landing-zone recognition, and visual tracking computed onboard.

Fail-Safe Systems

Automated Return-to-Launch, obstacle fallback, and low-battery management triggers.

02 — Key Features

An integrated autonomy pipeline

Every subsystem is designed to work together — from sensing and estimation to planning and control.

State Estimation

Visual-Inertial Odometry (VIO) integrated with EKF for GPS-denied environments.

Trajectory Planning

Dynamic occupancy-grid mapping with real-time 3D path and trajectory optimization.

Target Detection

Edge-computed YOLOv8 pipeline for detection, landing-zone recognition, and tracking.

Fail-Safe Triggers

Return-to-Launch, obstacle fallback avoidance, and low-battery management.

Simulation Support

Full Software-In-The-Loop (SITL) environment with Gazebo and PX4.

Open Source

A fully documented, community-driven codebase ready for extension.

03 — System Architecture

From sensors to flight controller

A Pixhawk 6C flight controller paired with an NVIDIA Jetson companion computer over uXRCE-DDS / MAVLink.

Flight

Flight Control

Pixhawk 6C running PX4 v1.14+ handles attitude control, failsafes, RTL, and actuator output.

  • FMU PWM OUT 1–4
  • TELEM1 → SiK telemetry
  • TELEM2 → Jetson (uXRCE-DDS)
  • RC IN ← SBUS override
Compute

Companion Computer

NVIDIA Jetson Orin Nano (Ubuntu 22.04 / JetPack 5.x) hosts the full autonomy stack.

  • VIO fusion & EKF
  • Occupancy-grid mapping
  • Trajectory planning
  • YOLOv8 detection & tracking
Perception

Sensing

Multi-modal perception for depth, odometry, and target imagery.

  • Intel RealSense D435i — depth + IMU (VIO)
  • IMX219 / RGB camera — detection feed
  • Holybro M10 GPS — global positioning
Comms

Communication

Multi-link connectivity for ground control and remote operations.

  • SiK radio 433/915 MHz — MAVLink GCS
  • RadioMaster R81 — SBUS manual control
  • WiFi / Ethernet — ROS 2 bridge & imagery

10 — Get Started

Clone, build, and fly in simulation

Jump into the workspace in three steps. Full details live in the documentation.

01

Clone

git clone https://github.com/the-robotronics-club/quadcopter
cd quadcopter
02

Build

cd src
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
03

Simulate

micro-ros-agent udp4 --port 8888 -v

# terminal 2: PX4 SITL + Gazebo
make px4_sitl gazebo

# terminal 3: autonomy bring-up
ros2 launch quadcopter_bringup sitl_simulation.launch.py
